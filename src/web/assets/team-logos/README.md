# Team logos

Put SVG team logos in this folder. Name each file using its Sportmonks team ID from the `id` column in your season's `teams.csv`.

For example, Samsunspor has ID `2811`:

```text
2811.svg
```

Use a lowercase `.svg` extension. Transparent backgrounds work best; logos are fitted within 32 × 32 pixels without stretching.

Oyuncu Listesi displays these logos between Rank and Role. Players associated with multiple clubs in the loaded season show each club's logo. Hover over a logo to see the club name. Missing logos display the club abbreviation instead of a broken image.

These are website assets, so keep them here rather than in the downloaded `data/` folder. Refresh the page after adding files, then reopen the season CSVs if needed. The supplied SVG logos for all 18 teams have been renamed to their Sportmonks IDs from the 2026/2027 `teams.csv`.
